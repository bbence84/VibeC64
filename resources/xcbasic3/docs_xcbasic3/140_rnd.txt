====== RND ======

The ''RND()'' function returns a pseudo-random floating point number, between 0 and 1.

===== Function header =====

  DECLARE FUNCTION RND AS FLOAT () SHARED STATIC INLINE

===== Example =====

  ' Display a sequence of 10 random numbers
  RANDOMIZE TI()
  FOR i AS BYTE = 1 TO 10
    PRINT RND()
  NEXT
