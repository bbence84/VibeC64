====== RNDB ======

The ''RNDB()'' function returns a pseudo-random 8-bit unsigned number, between 0 and 255.

===== Function header =====

  DECLARE FUNCTION RNDB AS BYTE () SHARED STATIC INLINE

===== Example =====

  ' Display a sequence of 10 random numbers
  RANDOMIZE TI()
  FOR i AS BYTE = 1 TO 10
    PRINT RNDB()
  NEXT
